# Local AI Model Weights

This directory holds offline GGUF model weights for local emergency NLP extraction using llama.cpp.

### Required Model
- **File:** `qwen2.5-0.5b-instruct-q4_k_m.gguf`
- **Location on device:**
  `/sdcard/Android/data/com.sethu.emergency/files/qwen2.5-0.5b-instruct-q4_k_m.gguf`
  or internal app directory as detected by `OfflineAiExtractor.kt`.

*Note: The binary weights file (~491 MB) is omitted from Git version control due to GitHub's 100 MB file size limit.*
